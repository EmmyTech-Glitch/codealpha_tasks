# Project Overview
This project presents an interactive Global Health & Epidemiological Analytics Dashboard. The primary objective is to automate the extraction of unstructured and semi-structured public health data from the World Health Organization (WHO) official platform using Python, clean and structure the dataset, and build a Power BI dashboard to analyze global disease outbreak trends, geographical distributions, and case severity.

# Data Source & Web Scraping Pipeline
Data was programmatic extracted from the World Health Organization (WHO) portal using a automated Python workflow

 ## Scraping Workflow Breakdown
 HTTP Requests & Parsing: Automated HTTP GET requests targeted WHO Disease Outbreak News (DONs) and health reporting pages using standard Python libraries (requests, BeautifulSoup).

 # Problem Statement
 Public health surveillance data published in narrative, text-heavy reports presents several data analysis challenges:

Unstructured Narrative Data: Critical metrics like total confirmed cases, fatalities, and regional transmission statuses are embedded in long paragraphs rather than structured tables.

# Business & Public Health Value

Manual Data Aggregation: Healthcare analysts frequently spend hours manually logging data from outbreak notices into spreadsheets.

Delayed Risk Assessment: Without automated data ingestion, identifying emerging geographical hot spots or cross-border transmission patterns in real time becomes difficult.
